FROM BROWSER PREVIEW TO REAL INSTALLATION

THE FIVE-PROJECTOR CONNECTION PLAN

The goal is five separately addressable projector feeds from one Windows desktop. The browser prototype is the show-control concept; the computer's graphics hardware and a projection-mapping/output system provide the physical picture feeds.

HDMIDisplayPortVGA
01 · Computer outputs

Choose a Windows desktop with a graphics setup verified to drive five independent displays at the projectors' actual resolutions and refresh rates. A common four-output gaming GPU may not be enough by itself.

02 · Correct signal conversion

Use HDMI or DisplayPort for digital feeds where possible. Use a proper active HDMI-to-VGA or DisplayPort-to-VGA converter only for a projector that needs VGA. VGA carries video, not audio.

03 · Extend, map & test

Set Windows to Extend, identify each display, assign Projectors 1–5, then align and mask each image to its window or projection surface. Test one projector at a time before running the full show.

Important: a basic HDMI splitter duplicates one picture; it does not create five independent scenes. We will not choose a graphics card, dock, adapter, or splitter until the exact projector inputs and computer output hardware are confirmed. The calibration grid is a visual alignment aid only; precise edge blending, masking and geometric warping require projection-mapping software or projector hardware that supports those adjustments.

What works today: the page provides five browser preview panels, five launchable output windows, and same-browser-window synchronization for show state. What is not connected yet: five physical projector signals, per-projector calibration/warping, smart lights, fog, and outdoor equipment. Those require suitable Windows display hardware and compatible external controllers.
